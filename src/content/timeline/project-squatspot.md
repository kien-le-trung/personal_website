summary: "SquatSpot is an AI squat coach that evaluates form from a side-view video. It uses MediaPipe to extract pose landmarks and biomechanical features, then classifies issues using a lightweight SVM. A stereo pipeline reconstructs 3D poses from synchronized front and side views, which serve as privileged training data in a LUPI framework. This distills richer 3D biomechanical knowledge into a model that needs only a single side-view video at deployment."
